CCNA IP Configuration, Routing & OSPF Network

A Cisco Packet Tracer networking project focused on IPv4 configuration, router configuration using CLI, routing, and dynamic routing using OSPF.

1-Project Overview.

This project show the configuration of a routed network using Cisco Packet Tracer and Command Line Interface (CLI).

The main objective is to configure network interfaces, establish routing between different networks, and implement OSPF as a dynamic routing protocol.

2-Project Tasks

2.1. IP Configuration
- Configure IPv4 addresses on router interfaces.
- Configure subnet masks.
- Enable router interfaces using CLI.
- Configure end devices with the required network settings.

2.2 Routing Configuration
- Configure routing between different networks.
- Use Cisco IOS CLI commands to configure and verify routing.
- Test connectivity between connected networks.

3.2. Dynamic Routing using OSPF
- Configure OSPF on the routers using CLI.
- Assign routers to OSPF Area 0.
- Advertise the required networks.
- Verify OSPF neighbor and routing information.
- Test end-to-end connectivity between different networks.
